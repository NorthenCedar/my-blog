三套视觉草案

direction C · high-contrast editorial

三套都在「高对比编辑风」这个已定方向内，但走法完全不同。每套都排了你那三篇真草稿 —— 长文、技术文、短文（带 3 张照片），桌面和手机都能看。挑一套，或者说要哪套的哪部分。

A · 索引式

swiss grid / index

瑞士网格 + 目录感。列表是三列排布（日期 / 标题+摘要 / 标签），文章页左侧有 sticky 侧栏放目录和标签。信息密度最高，最适合「我有很多篇」的那种站。

首页 长文 技术文 短文

B · 海报式

poster / color band

满幅黑块 + 超大标题。首屏一整块黑，文字压底对齐；列表用超大标题堆叠，hover 时整条变橙。视觉冲击最大，代价是长文读到一半时页面会比较"吵"。

首页 长文 技术文 短文

C · 印刷品

restrained print

极致克制。没有色块、没有超大标题、几乎没有橙色，靠细线和留白分层，列表像一本书的目录。最安静、最耐读，代价是「不像设计过」的风险。

首页 长文 技术文 短文

三套都遵守已冻结的决策：黑底代码块 · 双 token 强调色（#E4572E 只给 ≥24px/hover/图形，#C2410C 给小字）· 无暗色模式 · 零第三方脚本 · 无网络字体。

注意：原型用的是系统回退字体（本机没装 Archivo / Public Sans，实际落在 Segoe UI + Noto Sans SC），最终站点会自托管字体子集，字形观感会有变化。也还没有接代码高亮 —— 那是阶段 6 用 Astro 内置 Shiki 做的。
