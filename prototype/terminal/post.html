高三那年我买了台相机

高三最忙的那年，我买了人生第一台相机，从此看世界多了一个借口。

买相机这件事我准备了很久，久到后来我已经分不清我到底是想拍照，还是想给自己找一个从书桌前站起来走走的理由。那年冬天的教室很闷，窗玻璃上永远有一层雾。

第一台相机

它不贵，也不是什么好机器。我第一次把它拿在手里的时候，甚至不确定快门在哪。但我记得那个下午的光，记得我按下的第一张照片——拍糊了，是一棵树的枝桠和一块过曝的天空。

后来我才明白，一张照片是不是"好"，和它有没有被拍糊关系不大。这件事我用了一年才想通。

我拍的其实不是风景

有个说法是，拍照是为了留住时间。我一开始也这么以为，后来发现不是——照片留不住时间，它只留下你在那个时刻的注意力。

你按下快门的那一秒，是你这一天里唯一一秒真正在看。

所以我现在很少连拍。一张就好，拍不到就拍不到，明天再来。

设备清单与几个参数

记在这里是给自己看的，省得每次都去翻设置。

项目值备注
机身入门级 APS-C够用
常用焦段35mm 等效接近人眼，别想太多
导出长边 2400px / JPEG q90上线前统一处理

导出这一步我写了个脚本，省得每次手动点：

// 统一导出：长边 2400、质量 90
for (const f of files) {
  await sharp(f)
    .rotate()                    // 先把 EXIF 方向烘焙进像素
    .resize({ width: 2400, withoutEnlargement: true })
    .jpeg({ quality: 90, mozjpeg: true })
    .toFile(out(f));
}

写到这儿其实没什么结论。相机没有让我变好，它只是让我多看了几眼。如果你也在高三，我建议你先别买 —— 除非你真的很想从书桌前站起来走走。
