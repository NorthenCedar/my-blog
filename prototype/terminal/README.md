## 怎么打开

直接双击任意 `.html` 文件即可（`file://` 协议下可用，无需服务器）。

```
prototype/terminal/
├─ home.html       首页 · 扫描视场
├─ post.html       文章页 · 纯阅读
├─ gallery.html    相册页 · 瀑布流 + 自写灯箱
└─ projects.html   项目页 · 卡片 + 空态
```

**依赖说明**：四个文件都是自包含的单文件（CSS 与 JS 全部内联）。只有两类外部资源，
都是同仓库内的相对路径，不是第三方依赖：

- `../fonts/` —— 自托管字体（Archivo 宽体变体 + IBM Plex，OFL）
- `../../content/gallery/` —— 站主的真实照片

## 每个文件演示什么

| 文件 | 演示 |
|---|---|
| `home.html` | 扫描视场：固定扫描带驱动的聚焦、左侧刻度尺（位置仪表 + 区段导航）、折线分层、250vh 节奏预算 |
| `post.html` | 纯阅读：**没有**扫描带 / 聚焦 / 钉住；装饰只在外框（标题区、目录、相邻导航、评论），正文流内干净 |
| `gallery.html` | 瀑布流 + 自写灯箱（Esc 关闭 · ←/→ 切换 · Tab 不逃出 · 无 JS 时仍是完整瀑布流） |
| `projects.html` | 空态（站主的真实状态）+ 折叠的卡片布局示意 |

## 这些草案里固化了的决策

- **弱化下限 0.65**：`--ink` 以 0.65 不透明度叠在纸上合成 `#686867`，对纸 **5.33:1**，正文仍达标。
  **禁止更低** —— 0.18 时合成 `#D2D2CF`，只有 1.45:1，完全不可读（这是原提示词里的一个错误）
- **窄屏完全取消弱化**（全部 100%）；「场」的感觉由间距节奏与顶部刻度条承担
- **`prefers-reduced-motion` 与无 JS 时一切 100%**
- **聚焦的主要载体是线宽与角标**，透明度只做辅助
- 配色每个值都实测过对比度；绿色分三档（纸上 / 面板上 / 黑带上，三档不同）
- 不用圆角、不用阴影、不用渐变；层次由线宽、角标、位置、透明度承担
- 无抓取把手（站主拒绝：与原生滚动/移动端惯性打架，0.8 KB 换一个 bug 源不划算）

## 断点

| 断点 | 折线偏移 | 弱化 | 刻度尺 | 扫描带 |
|---|---|---|---|---|
| ≥1024 桌面 | 全量 0 / 6% / −4% / 12% | 0.65 → 1.0 | 左侧竖条 + 百分比读数 | 视口 50%，驱动聚焦 |
| 768–1023 平板 | ×0.6（0 / 3.6% / −2.4% / 7.2%） | 0.72 → 1.0 | 收窄，去掉百分比 | 同上，判定带略窄 |
| <768 手机 | **归零** | **取消**（全部 100%） | 顶部横向刻度条 | 退化为底部 2px 进度线 |

## 这些草案**没有**覆盖的（诚实记录）

- 没有真实数据接线（文章/相册/项目都是硬编码的假数据，除了相册用的是真实照片）
- 没有实装 View Transitions 页面过渡（需要真实多页跳转才有意义）
- 没有测 JS 体积（草案里没有打包，数字要到实现阶段才准）
- 没有验证 `backdrop-filter`（按研究结论，只在灯箱遮罩用一次，草案里还没加）
- 没有做 404 页的警戒条纹
