# 站主视频与写作台发布兼容实施计划

目标：站主能在文章、说说插入视频；写作台保存与 AI 更新相遇时明确阻止覆盖，发布保留普通 Git 历史；修复主题软条的首次形态。

用户已要求先执行这两项。访客账户仅提供讨论方案，不写入本次产品代码。

## 接口与约束

- 视频原件统一入库 `content/videos/<sha256>.mp4|webm`，公开引用 `/videos/<同名文件>`。
- 允许 MP4 / WebM，单个不超过 25 MiB；不自动转码、不自动播放。
- 说说可选 `videos: [{src, alt}]`；文章使用有 controls / playsinline / preload="none" 的原生 video。
- 构建只导出已渲染 HTML 引用的视频，缺文件、伪格式、越界名或哈希不符即失败；草稿及未引用原件不部署。
- 写作台新增 `POST /api/video/upload`、`GET/HEAD /api/video?name=...`，只允许管理原件目录内的视频，支持字节区间。
- 文章、说说、日志 GET 返回 `revision`，保存和删除携带 `base_revision`；版本过期返回 409，页面中的未保存内容保留。
- `lib/gitops.py` 提供 `preflight(repo)`；构建前后检查工作区状态，发布不再使用 API 重造提交或 soft reset。
- 检测到内容范围外的工作区改动、远端领先或分叉时，写作台阻止发布并说明同步要求。推送禁止 force。
- 已有未提交的标签绿光与页脚布局改动必须保留，本次不自动推送。
