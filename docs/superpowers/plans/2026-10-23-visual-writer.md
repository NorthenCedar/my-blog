# 写作台可视化编辑与文章目录

用户已确认：云端默认可视化编写，保留 Markdown 模式；本地增加统一的正文、章节标题、小标题操作。文章发布后沿用现有 H2/H3 目录。直接在本会话实现。

## 实现约束

- 继续以 Markdown 字符串保存、恢复和发布，不修改数据库、鉴权、发布权限。
- ProseMirror 只由 `/write/` 加载。使用其 CommonMark 解析、编辑、撤销与序列化，避免自行实现输入法和选区。
- 未编辑正文时，保存和切换模式逐字保留原 Markdown。普通格式编辑允许规范化 Markdown；HTML/视频、表格、脚注、扩展语法明确退回源码，禁止静默丢弃。
- 链接仅允许 HTTP(S)/邮件；图片继续只显示受控同源私密地址。粘贴富文本按纯文本处理，保留图片上传流程。
- 样式沿用写作台的纸色、文字色和强调色 token，移动端工具换行、正文不横向溢出。

## 审查重点

1. IME 中文输入及工具栏选区不能丢失，程序设置文档不得产生误保存循环。
2. 旧文未知语法、CRLF、代码和视频不得在切换/保存时静默改变。
3. 可视化插入图片必须同时保留草稿资产引用，禁止外部追踪图片和粘贴 HTML 执行。
4. 编辑器销毁与异步响应不得写入另一个草稿；离线恢复仍只存 Markdown。
5. 编辑器依赖不得进入公开访客页面，手机页面不得横向溢出。
