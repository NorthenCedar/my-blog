# 单册灯箱与阅读目录动效

用户要求开始实现这两项，沿用本地体验流程，不发布。

单册照片墙：实际大档照片从缩略图位置放大进入灯箱，关闭回到当前已显示照片的缩略图；目标不在视口时短淡出。换图采用短水平位移，图片可绘制后才同步图注，不引入缩略图占位或双层照片。保持循环切换、Esc、焦点约束、背景锁定、修饰点击原图、原生链接回退。慢图显示加载提示，关闭或新请求使旧解码失效。减少动态或引擎未就绪立即切到终态。手机缩放和页面离开清理动画与滚动锁。

文章目录：保留原生锚点、URL与浏览器历史；当前节标记用细线平滑移动，并与现有aria-current同步。目录内部独立滚动时指示线保持对应位置；切换章节时只在需要时将当前目录项带进目录可见区。首屏不下载GSAP，第一次阅读滚动或目录交互后才预热；没有库、减少动态时同样准确定位。手机仍放在正文上方，无新增悬浮抽屉。

复用现有GSAP3.15.1及Flip加载器，无新依赖。不改螺旋盘、相册入口或三维场景。PowerShell固定7.6.9，颜色走tokens，保留大档加载与预取契约。
