# 访客账户：账密、名片与资料设置

状态：用户于 2026-10-20 确认「可识别身份、公开名片＋私人的资料设置页」，随后明确选择「账密登录，开始做吧，有不确定的就来问我」。本次据此在现有工作区实施；不推送，不执行远端数据库迁移，不创建外部服务。

## 目的与范围

让愿意长期留言的访客拥有可识别的身份。匿名访客继续直接填写名字、正文发表，不自动弹登录框或跳转。文章、说说、留言板及两层回复均显示头像与昵称；账户昵称可打开名片，展示签名及站主标识。资料设置仅向本人返回，公开接口不返回登录名、密码摘要、恢复码或会话。

使用唯一自定义登录名与密码，暂不收集邮箱、手机号；没有验证码与发送服务。登录名 3–32 位小写英文字母、数字、下划线、连字符；昵称 1–40 字，签名 0–160 字。密码 15–128 字符，允许空格与 Unicode、不裁剪密码、不强制字符种类。昵称可以重复，站主身份只由服务端 OWNER_USER_ID 绑定，不能由昵称或注册先后获得。北杉、站主、管理员等易误认的昵称由站主保留。

## 注册、登录与恢复

入口在评论编辑区及账户页。登录面板在原页打开，关闭或失败保留留言正文；登录后默认以账户发表，也可以主动选择匿名。回复使用同一身份选择。会话失效时不自动将原定账户留言改为匿名，提示选择匿名或重新登录；正文仍保留。

注册产生随机内部账户 ID、独立盐、scrypt（N=32768、r=8、p=3）密码摘要，以及随机 256 位恢复码。恢复码仅首次返回，服务端只存摘要；注册和换码界面提供下载。恢复需账号、恢复码与新密码；成功后恢复码轮换、所有旧会话撤销。丢失密码及恢复码且无有效会话时不能可靠找回，界面明确告知。换密码、换恢复码和注销必须再次验证当前密码。注销清除资料、头像、登录名、凭据及会话；已发表内容保留原发表昵称并去除账户关联，转为匿名，不自动删除其他人的回复。

会话令牌随机 256 位，数据库仅存 SHA256 摘要，有效期 30 天。HTTPS 使用 __Host- 前缀、HttpOnly、Secure、SameSite=Lax、Path=/ Cookie；仅 localhost/127.0.0.1 HTTP 预览使用独立开发 Cookie。账户及身份接口 no-store。写操作要求同源 Origin、JSON 与自定义请求头；头像上传也要求相同同源保护。匿名旧客户端继续可提交，携带账户 Cookie 的评论必须明确声明身份，不能依赖客户端传 author_id/name 获取身份。

注册、登录、恢复、资料写入按动作和 IP 摘要限频，登录/恢复额外按登录名摘要限频，数据库原子累计防并发绕过；限频先于密码运算。错误统一，不区分账号不存在与密码错误。不记录密码、恢复码和会话值。

## 资料与头像

设置页可改昵称、签名，选择六款本站自绘莱茵风格默认头像：叶脉、双螺旋、实验瓶、晶体、星轨、无限环；可上传自己的图片。浏览器先将自定义图转为 128×128 静态 PNG，服务端独立校验尺寸、解压长度、PNG 结构并清理元数据；拒绝 SVG、动图原件、超限文件和异常压缩数据。数据库存小尺寸头像，公开头像接口只返回 image/png 并设置 nosniff。默认头像为本站原生 SVG 图形，不依赖第三方头像服务。

匿名及历史留言按留言稳定标识分配默认头像，保留原有昵称正文。账户改昵称/头像后，历史关联留言显示最新公开资料；注销后恢复发表时快照昵称。名片只展示昵称、头像、签名和可信站主标记，不展示历史评论清单。

## 数据与模块

沿用 Pages Functions + D1。新增可重复执行的 0004 迁移：visitor_accounts、visitor_sessions、visitor_rate_limits、comment_authors 四表；不 ALTER 既有评论/回复表。评论与身份关联在一次 D1 batch 事务内写入，数据库唯一约束保证登录名和留言身份唯一。写作台现有 ADMIN_TOKEN 管理接口及 Bearer 鉴权保持兼容，访客 Cookie 不赋予管理权限。

服务端拆分密码/输入核心、会话与限流、头像验证、账户动作、公开资料及评论关联；前端拆分身份渲染、登录面板、设置页。仍使用原生 TypeScript/Astro、现有 token、全站主题与移动布局。登录与名片在点击时创建 DOM，设置表单仅在账户页加载。新增能力引起的 JS 增量须实测并在预算中说明，不能漏算动态导入绕过预算。

实测构建取舍：Rolldown 将动态模块的命名空间 helper 放进主题开关大文件，内部 runtime 不参与手动拆分匹配。登录采用普通具名导入，消除约 470 KB 的渲染器牵连；增加约 7 KB 的完整评论闭包。文章预算 22 KiB、留言 28 KiB、说说 18 KiB，保留“渲染器只在关于页加载”的独立断言。
