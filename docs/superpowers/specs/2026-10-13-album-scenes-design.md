# 单册相册：散片画布与悬浮切片

用户已在会话中确认设计并要求直接开始，允许分阶段交付。本文记录会话决定，不另设审批关口。

## 内容与边界

- 只改变 `/gallery/<册名>/` 的陈列；总入口、显影板、螺旋盘和网址保持原行为。
- 相册 frontmatter 新增可选 `layout: scatter | slices`、`titleEn`；默认 scatter，英文名未填时回退中文。
- 人像和酸橙用散片，一些风景用切片。照片仍按 images 排列、使用原有两档 WebP。
- 不增依赖或外部请求。照片不裁切、不改色。大档只在打开灯箱时加载。

## 两种陈列

散片：铺满视口的画布以英文标题为中心，周围照片按稳定种子疏密错落排列，尺寸与角度各异，使用浅色花边和轻微羽化柔化边缘。拖空白四向平移，松手后继续滑行；有界缩放和回到中心可恢复初始视野。追加照片保留已有位置，画布边缘的照片暗示可继续探索。

切片：铺满视口的照片在前后错开的平面中排列，拖动、滚轮和前后按钮沿序列浏览；下滚让照片左移、上滚右移，输入停止后继续滑行。当前照片完整呈现，其他照片显示纵深，两侧随距离渐入渐出。角度限制在舒适范围，不做自由飞行。切片序列始终保持 images 顺序。

共同：点击照片直接打开灯箱；拖动不会误点；关闭灯箱保留场景位置。提供查看全部/返回展览；静态 HTML 就是完整索引，脚本初始化成功才进入全屏场景，减少动效和无 JS 使用索引。键盘能逐张到达、查看、关闭；手机可切到完整索引正常滚动。桌面新增按钮沿用站内圆形光标。

## 实现

内容选项解析与散片位置、切片位姿、缩放边界放在纯模块，独立测试。新场景组件复用现有 PhotoWall 的真实照片链接和灯箱，按渐进增强方式移动同一批 figure，不复制照片或灯箱。原始砖墙保留为完整索引及回退。

## 验收

验证默认与非法 layout、英文回退、CRLF、单张/多张/57张、重复照片拒绝、散片追加位置稳定、切片顺序及边界。构建后所有相册有同一组原始照片；手机/无 JS/reduce 可看全；灯箱和返回位置正确；全量 npm run verify。
